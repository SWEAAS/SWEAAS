# SWEAAS Full-Stack Live-Data Audit — 2026-04-24

## Executive summary

Verified against the **live local stack**: backend bare-metal uvicorn on :8000 (reading shared `/Users/jeffreyoduman/SWEAAS/.env` with **every integration key populated**), frontend Vite on :5173, Postgres in `gallant-pascal-4547f4-postgres-1`. Prod `api.sweaas.com` was 503 for the entire audit window — Phase 2 not executed.

**Verdict:** The UI is largely driven by real API calls and DB rows, but **at least four customer-visible surfaces are actively lying to users**: SMS delivery (falsely reports "delivered"), email delivery (same), Stripe Connect onboarding (returns raw 500 instead of a useful error), and the Budget Consumption percentage (shows 0% while token-usage log holds ~1M tokens).

## Fix-order triage (recommended)

**P0 — customer-visible lies (ship today):**
1. Add `twilio>=9` to `pyproject.toml`; normalize phone to E.164 in `update_contact_info`; surface `sent=False` back to the `SendNotificationResponse`.
2. Update the AgentMail SDK call signature to match 0.4.15 (drop `display_name=`), or pin to the older SDK that accepts it.
3. Fix `_pref_to_response` to avoid lazy-load after flush (either `await db.refresh(pref)` or return fields from the request payload). Dedupe the duplicate `notification_preferences` rows already in DB.

**P1 — commerce is down:**
4. Enroll the platform Stripe account in Connect (Stripe Dashboard → Connect → Get started). Alternatively, swap `.env` to an already-enabled test account.
5. Wrap `stripe.Account.create` (and similar calls) in a try/except `stripe.error.StripeError` → `HTTPException(400, ...)` so the UI can render the real message.
6. Replace hardcoded `app.sweaas.dev` `success_url` / `cancel_url` in `budget_service.py:158-161` with config-driven values (or remove the legacy `/budget/checkout` path entirely in favor of `/stripe/checkout`).

**P2 — architectural rot:**
7. Persist `agent_sessions` to DB inside `OrchestrationService.execute` (or remove the table and the sessions tab from the UI). Today: 0 rows ever, after 52 reports + 754 token logs + successful C10 run.
8. Consolidate budget token counting to a single source (`token_usage_logs` is the log of record). `agent_configs.tokens_used_today` should either be derived from it on demand or removed.
9. `/communication/cto-context.active_tasks` should query actual active orchestrations instead of returning `[]`.
10. Decide whether the budget estimate should be data-driven; if not, remove `monthly_budget_usd` from the request schema so callers stop thinking it matters.
